## 질문 (돌리기 전에 쓴다)

`20261123-reasoning-explain`은 DeepSeek Eco(추론 끔)에서 셀 간 분산비 3.38, 셀 편차 정렬 0.479를 얻었다. 이 "집단 차이 과장"이 DeepSeek만의 성질인지, K-EXAONE·Haiku에도 있는지 본다. 보고서(`research/summary_20261123.md` 4절 작업 C)의 가장 큰 주장을 한 모델에서 세 모델로 넓힐 수 있는지가 걸려 있다.

돌리기 전에 아는 것: DeepSeek Eco 끔의 값(위)과, 11/15 test 49문항에서 본 셀 이동 TVD(사람 0.075, K-EXAONE 0.124, DeepSeek 0.209, Haiku 0.246). K-EXAONE·Haiku의 분산비·정렬은 아직 보지 않았다.

## 가설과 판정 기준 (돌리기 전에 쓴다)

방향 예측은 두지 않는다.

**주 지표** (모델마다, 문항 부트스트랩 2,000회, 95% 구간)

| 지표 | 정의 (`20261123-reasoning-high-full/run.py`와 같다) |
|---|---|
| 셀 간 분산비 | Σ문항 V모델 / Σ문항 V사람. V = Σ셀 w(s셀 − s̄)²에서 표집 잡음 기댓값을 뺀 값. w = `cells.csv`의 pop_share |
| 셀 편차 정렬 | 문항·셀을 모은 가중 상관 Σ w·d모델·d사람 / √(Σ w·d모델² · Σ w·d사람²) |

**판정**
- 모델별 과장: 분산비의 95% 구간 하한이 1보다 크면 그 모델은 "과장 있음".
- 세 모델 모두 "과장 있음"이면 보고서에 "집단 차이 과장은 세 모델 공통"으로 쓴다. 일부만이면 해당 모델로 한정한다.
- 정렬은 판정에 쓰지 않고 함께 보고한다(0보다 큰지, 구간).

**탐색** (보정 없음, "탐색"으로 표기)
- 기울기 Σ w·d모델·d사람 / Σ w·d사람².
- 모델 간 짝지은 차이(같은 부트스트랩 문항 표본): 분산비·정렬, 세 쌍.
- 같은 정의로 DeepSeek Ultrafast(k=100)와 DeepSeek Eco 끔(k=50, 기존 결과 3.38/0.479)이 비슷한지 확인한다(엔드포인트·k 차이 점검).

## 방법

`run.py` 하나다. 지표 함수(`stats`, `parts`, `agg`)는 `experiments/20261123-reasoning-high-full/run.py`에서 그대로 옮긴다. 원응답 대신 `counts_k100.npz`의 개수 텐서 C[모델, 페르소나, 문항, 보기]를 쓴다(셀별 표본 수는 개수의 합). 신규 API 호출 없음.

출력: `out/primary.csv`(모델별 주 지표와 판정), `out/explore.csv`(모델 간 차이, 기울기), `out/run.log`, `out/run.json`.

## 결과 (돌린 뒤 쓴다)

실행: 2026-11-26, 커밋 90483b1, 미커밋 변경 없음(`out/run.json`). 신규 호출 0. 대상: test 제외 197문항 중 순서형·이진 188문항, 10셀.
셀·문항당 유효 표본 수 평균 K-EXAONE 100.0, DeepSeek 100.0, Haiku 99.3(최소 10: 거부가 많은 셀·문항).

**주 지표** (`out/primary.csv`, 문항 부트스트랩 2,000회)

| 모델 | 셀 간 분산비 [95%] | 셀 편차 정렬 [95%] | 판정 |
|---|---|---|---|
| K-EXAONE | 2.70 [1.93, 3.57] | 0.574 [0.462, 0.651] | 과장 있음 |
| DeepSeek (Ultrafast) | 3.37 [2.33, 4.79] | 0.505 [0.386, 0.586] | 과장 있음 |
| Haiku | 6.70 [4.60, 9.95] | 0.374 [0.251, 0.478] | 과장 있음 |

세 모델 모두 분산비 95% 구간 하한이 1보다 크다. 판정 기준에 따라 **집단 차이 과장은 세 모델 공통**이다.

**탐색** (`out/explore.csv`, 보정 없음)
- 기울기: K-EXAONE 0.85 [0.62, 1.05], DeepSeek 0.83 [0.58, 1.05], Haiku 0.86 [0.55, 1.13]. 세 모델 모두 사람 방향 성분의 폭은 사람과 비슷하거나 약간 작다. 분산비가 큰 것은 사람과 무관한 성분이 크기 때문이다.
- 모델 간 차이: Haiku는 분산비가 K-EXAONE보다 +4.00 [2.18, 7.06], DeepSeek보다 +3.33 [1.65, 5.99] 크고, 정렬은 각각 −0.200 [−0.274, −0.125], −0.130 [−0.228, −0.016] 낮다. DeepSeek − K-EXAONE은 분산비 +0.67 [−0.27, 1.78](차이 불분명), 정렬 −0.069 [−0.147, −0.002].
- 점검: DeepSeek Ultrafast(k=100) 분산비 3.37·정렬 0.505는 DeepSeek Eco 끔(k=50, `20261123-reasoning-explain`) 3.38·0.479와 거의 같다. 엔드포인트와 k 차이가 결론을 바꾸지 않는다.
- 순서는 11/15 test의 셀 이동 TVD(K-EXAONE 0.124 < DeepSeek 0.209 < Haiku 0.246)와 같다.

## 결론

집단 차이 과장(셀 간 분산비 > 1)은 세 모델 공통이다: K-EXAONE 2.70, DeepSeek 3.37, Haiku 6.70. 방향 정렬은 K-EXAONE 0.57 > DeepSeek 0.50 > Haiku 0.37로 과장이 클수록 낮다.
