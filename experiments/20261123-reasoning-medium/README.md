## 질문 (돌리기 전에 쓴다)

추론을 low에서 medium으로 올리면 (1) 사람 분포와의 거리, (2) 셀끼리 차이의 크기, (3) 그 차이가 사람 셀 차이와 같은 방향인지가 어떻게 바뀌는가.

## 가설과 판정 기준 (돌리기 전에 쓴다)

- 가설: 방향 예측은 두지 않는다(양쪽 모두 가능).
- 판정: 주 지표 4개 모두 Holm 보정 p < 0.05면 "있음", 아니면 "없음"으로 적는다.
- 쓰는 문항 분할: calibration 148문항(β 고르기) / validation 49문항(확인). test 49문항은 쓰지 않는다.

### 주 지표 4개 (medium − low, Holm 보정)

1. 보정 후 사람 TVD, 한국 성인 (validation 49문항)
2. 보정 후 사람 TVD, 10셀 pop_share 가중 (validation 49문항)
3. 셀 간 분산비 (모델/사람, 잡음 뺀 값, test 뺀 순서형·이진 문항)
4. 셀 편차 정렬 (가중 상관, 같은 문항)

- 구간: 같은 문항끼리 짝지은 문항 부트스트랩 95%, 2,000회. p = 2·min(비율(차이 ≤ 0), 비율(차이 ≥ 0)).
- β: 설정(끔/low/medium)마다 페르소나 없음 하나, 한국 성인과 10셀이 하나. calibration 148문항에서 TVD가 최소인 값, 격자 0.05~1.5(0.005 간격).
- 지표 1·2는 `experiments/20261118-reasoning-effect/run.py`, 지표 3·4는 `experiments/20261123-reasoning-explain/run.py`의 정의를 그대로 쓴다. 함수는 복사하고 출처를 주석으로 남긴다.

### 탐색 (보정 없음, 결과에 "탐색"으로 표기)

medium − 끔(같은 4지표), 기울기, 이동 분해(공통 이동/셀 고유 이동), 무효율, 평균 추론 토큰, 끔→low→medium 추세 표.

## 방법

`run.py`가 하는 일은 위 지표 계산이다. 데이터는 추론 끔 `raw/v2/deepseek_eco_p1.jsonl`, low `raw/v2/deepseek_eco_low_p1.jsonl`, medium(새 파일)이고, 정답은 `counts_k100.npz`의 H·NEFF다.

## 결과 (돌린 뒤 쓴다)

수집: 147,600건 모두 받음. 무효율 0.0001(끔 0.0003, low 0.0032). 비용은 약 $3.9(러너 추정, `raw/v2/deepseek_eco_medium_p1.log`). 중간에 네트워크가 끊겨 `api_error` 42건이 생겼고 같은 명령으로 다시 받아 모두 채웠다.

### 탐색 (보정 없음)

- 추세 (`out/trend.csv`): 한국 성인 TVD는 끔 0.2687 → low 0.2648 → medium 0.2683, 10셀 TVD는 0.2837 → 0.2781 → 0.2766. 셀 간 분산비는 3.38 → 4.51 → 5.16, 정렬은 0.479 → 0.548 → 0.581, 기울기는 0.799 → 1.047 → 1.181. 평균 추론 토큰은 0 → 117.9 → 176.6.
- medium − 끔 (`out/explore.csv`): TVD는 한국 성인 −0.0004(−0.0187 ~ 0.0156), 10셀 −0.0071(−0.0243 ~ 0.0085)로 구간이 0을 지난다. 분산비 +1.78(0.55 ~ 3.19), 정렬 +0.102(0.033 ~ 0.185), 기울기 +0.382(0.158 ~ 0.607)는 구간이 0 위.
- medium − low 기울기 +0.134(0.033 ~ 0.238).
- 이동 분해 (`out/decomp.csv`, medium − low): 잡음을 뺀 공통 이동 제곱 0.0022(0.0016 ~ 0.0028), 셀 고유 이동 제곱합 0.0019(0.0012 ~ 0.0025), 10셀 평균이 사람 평균에 가까워진 정도 −0.0015(−0.0078 ~ 0.0049, 0 포함), 셀 고유 이동이 사람 셀 편차와 같은 방향인 정도(공분산) +0.00039(0.00009 ~ 0.00072).
- β (calibration 148문항): medium은 페르소나 없음 0.300, 한국 성인·10셀 0.350 (low 0.305·0.365, 끔 0.335·0.350).

## 결론

추론을 low에서 medium으로 올려도 사람 분포와의 거리, 셀 간 분산비, 셀 편차 정렬 모두 Holm 보정 뒤 유의한 변화가 없다(주 지표 4개 모두 "없음"). 탐색에서는 medium이 추론 끔보다 셀 간 분산비와 정렬이 크지만 TVD는 그대로다.
