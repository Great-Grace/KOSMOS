# KOSMOS Haiku 5.5 — 분포 직접 예측 arm 설계 (탐색 분석)

- 작성일: 2026-11-11
- 지위: **탐색 분석.** Stage 1 결과(Gate 1 FAIL)를 이미 본 뒤에 추가했다. 확증 결론으로 쓰지 않는다.
- 원 사전등록: `research/preregistration_haiku_pilot.md`. 이 문서는 그 설계를 바꾸지 않고 arm 하나를 덧붙인다.
- 아래 설정·지표·해석 규칙은 이 arm의 결과를 보기 전에 고정한다. 바꾸면 끝의 변경 이력에 이유를 적는다.

## 1. 왜 추가하는가

Stage 1에서 Haiku 5.5는 한 보기에 심하게 쏠렸다(`metrics/stage1_collapse_diagnostic.csv`).
모델 최빈 보기 확률 평균 0.83~0.88, 인간 0.52. 그런데 Haiku 5.5는 temperature를 기본값 외로 줄 수 없어
쏠림을 호출 설정으로 풀 수 없다. 표본을 더 뽑아도 차이는 줄지 않는다(`metrics/stage1_sampling_bound.csv`:
문항의 91~92%에서 모델 최빈 보기 확률의 95% 하한이 인간 비율보다 높다).

그래서 "쏠림"이 **표본 추출 행동**의 문제인지 **분포 지식**의 문제인지 가른다.

**RQ.** 역할을 맡겨 한 명씩 답하게 하는 대신 집단의 응답 비율을 직접 예측하게 하면, KGSS 분포에 더 가까운가?

## 2. 재료와 호출

- 문항: 확장 라운드 250문항. 문항·보기 텍스트는 `experiment_expand/experiment_probes.csv`의 `c0` 프롬프트에서 그대로 가져오고
  마지막 줄 `번호로만 답하십시오.`만 뺀다.
- 집단 15개: `한국 성인 전체` 1개 + 성별×연령 14셀(`한국의 22세 남자` 등, demo 페르소나 문구 재사용).
- 프롬프트 수: 250 × 15 = 3,750. 인칭·화계 조작은 하지 않는다(이 arm의 질문이 아니다).
- 조사명(KGSS)과 조사 연도는 밝히지 않는다. 회상 프로브(`kgss_contamination.py` E)와 구분하기 위함이다.
- 문구와 설정은 `research/haiku_pilot_config.json`의 `verbal` 항목 한 곳에 둔다.

| 항목 | 값 |
|---|---|
| 모델 | `claude-haiku-5-5` |
| thinking | 끔 |
| temperature | 지정하지 않음(기본값) |
| max_tokens | 120 |
| 반복 | 프롬프트당 k=5, 평균 |
| 처리 | 스모크(`verbal0`)는 단일 호출, 본실행(`verbal1`)은 Message Batches |

- 스모크 `verbal0`: Stage 0과 같은 20문항 × 15집단 × 1회 = 300호출. 통과 기준은 유효율 ≥ 95%.
  미달이면 system 문구만 고친다. 문항·집단 문구는 고치지 않는다.
- 본실행 `verbal1`: 3,750 × 5 = 18,750호출.

## 3. 파싱과 분포

- 응답에서 숫자를 순서대로 읽는다. 무효 유형: `refusal`(숫자 없음), `bad_count`(개수 불일치), `bad_sum`(합계가 100±2 밖 또는 음수).
- 무효는 버리지 않고 유형별로 센다.
- 유효 응답은 DK·비해당 보기를 뺀 뒤, 각 보기 최소 0.5%로 바닥 처리하고 정규화한다(NLL의 log 0 방지).
- 프롬프트별로 유효 응답을 평균해 예측 분포로 쓴다.

## 4. 지표 (Stage 1·2와 같은 정의)

- 모집단: `Q_pop` 대비 TVD, W1(정규화), 개인 NLL, NLL<균등 비율, 최빈값 일치율, 최빈 보기 확률.
- 비교 arm: 표본 추출 `sampling_adult`(Stage 1 adult 4조건 표본 합산 + Jeffreys 0.5), `sampling_c0`, 균등분포.
- 대응 비교: 문항별 (직접 예측 − 비교 arm) 차이, 문항 클러스터 부트스트랩 2,000회, 95% CI.
- 서브그룹: 14셀에서 `(E[P_c] − E[P_pop])`와 `(E[Q_c] − E[Q_pop])`의 문항별 상관, 문항 중앙값, 셀 라벨 순열검정 2,000회.
  타겟 정렬 이득 `TVD(P_c, Q_pop) − TVD(P_c, Q_c)`.

## 5. 해석표 (미리 고정)

| 결과 | 해석 |
|---|---|
| 직접 예측의 TVD·NLL이 표본 추출과 균등보다 낮고 CI가 0을 넘지 않음 | 분포 지식은 있다. 병목은 역할극 표본 추출의 쏠림이다. |
| 표본 추출보다는 낮지만 균등보다 낮지 않음 | 쏠림은 풀리지만 위치 지식이 부족하다. |
| 표본 추출과 차이가 없거나 더 나쁨 | 분포 지식 자체가 부족하다. 추출 방식의 문제가 아니다. |
| subgroup r 중앙값 > 0.2 이고 순열 p < 0.05 | 집단 차이의 방향은 안다. |

## 6. 한계 (미리 기록)

- Haiku 5.5는 Claude 계열 최하위 체급이다. 결론은 "경량 상용 모델"까지만 쓴다. 프론티어 모델 전반으로 넓히지 않는다.
- 직접 예측은 실리콘 샘플링(개인 역할극)과 다른 과제다. 이 arm이 잘 나와도 "역할극 표본이 인간을 대체한다"는 뜻이 아니다.
- KGSS 2023 공개 집계가 학습 자료에 있었을 수 있다. 직접 예측은 회상에 더 가깝게 작동할 수 있으므로 오염 가능성을 한계로 적는다.
- 서브그룹 정답지는 표본이 작다(n<20이면 60+로 백오프). 인간 쪽 노이즈가 상관을 낮춘다.
- 0.5% 바닥 처리, 합계 허용 ±2는 연구자 선택이다.
- 비용 산정과 승인 기록은 `research/cost_estimate_verbalized_arm.md`.
