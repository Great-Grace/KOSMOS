# demo(성별+연령) 조건 분포 재현 타당성 검증 (기존 지표 vs 수정 지표 비교)

## exaone
- 문항 125개 / 프로브 5000건 / 평균 선택지확률질량 0.9999
- **Wasserstein 및 TVD 거리 비교**:
  - 기존 산식 (개별 평균 $\frac{1}{N}\sum_i W_1(P_i, Q)$): **0.6133** (개별 평균 TVD: **0.4109**)
  - 수정 산식 (모집단 집계 $W_1(\sum_i w_i P_i, Q)$): **0.6020** (차이 -0.0113 / 동일가중 $w_i=1/N$ 집계: **0.6025**)
  - 수정 산식 TVD ($\mathrm{TVD}(\sum_i w_i P_i, Q)$): **0.4000** (동일가중 $w_i=1/N$ TVD: **0.4013** / 균등분포 TVD 기준선: **0.3313**)
  - 균등분포 기준선 (Uniform $W_1$ Baseline): **0.5482** (수정 산식 - 균등기준선: +0.0538)
  - 전체 최빈 원핫 기준선 (Marginal Modal 1-hot $W_1$): **0.4998**
  - 전체 중앙값 원핫 기준선 (Marginal Median 1-hot $W_1$, 최적 점질량): **0.4912**
  - 셀 조건부 Wasserstein ($\sum_c w_c W_1(P(Y|c), P_{KGSS}(Y|c))$): **0.6171** (비가중 셀 평균: 0.6221 / 셀 조건부 가중 TVD: 0.4131)
- **엔트로피 분해 (모드 붕괴 점검, 가중 vs 비가중)**:
  - 모델 조건부 엔트로피 (가중 $\sum_i w_i H(P_i)$ / 비가중 $\frac{1}{N}\sum_i H(P_i)$): **0.908bit** / **0.905bit**
  - 모델 모집단 집계 엔트로피 (가중 $H(\sum_i w_i P_i)$ / 비가중 $H(\frac{1}{N}\sum_i P_i)$): **0.941bit** / **0.939bit**
  - 페르소나 상호정보량 $I(Y; X)$ (가중 / 비가중): **0.033bit** / **0.034bit** (실제 인간 응답 엔트로피: **1.386bit**)
- **subgroup r (성별×연령 10셀 평균)**:
  - 기존 산식 (모델 미중심화): **0.001** (범위 -0.316~0.201)
  - 수정 산식 (동일 관측셀·FINALWT 가중 중심화): **0.183** (범위 0.047~0.385, 문항 부트스트랩 95% CI [0.115, 0.251] / 배터리 클러스터(92개) 부트스트랩 95% CI [0.108, 0.259])
  - 수정 산식 (동일 관측셀 비가중 중심화): **0.182**
  - 수정 산식 (척도 폭 [0,1] 정규화 중심화): **0.284**
  - 문항 내 10셀 상관 평균: **0.040**
