## 1. [최우선] Demo 모집단 집계 가중치 오류 수정 및 End-to-End 재검증

### 1.1 오류 원인 및 수학적 수정
- **원인**: 2차 수정 당시 [`kgss_c0_validity.py`](../kgss_c0_validity.py) `score()` 함수(구 line 262)는 `aggregate_demo_cells()`가 반환한 셀별 정규화 가중치 $\tilde{w}_c$를 셀 $(s, a)$에 속한 모든 프롬프트 행 $i \in c$에 그대로 부여하였다($w_i = \tilde{w}_c$).
  - 셀당 프롬프트가 1개인 원본 `original_demo`(10셀×1프롬프트)에서는 $n_c = 1$이므로 문제가 드러나지 않았으나,
  - 셀당 프롬프트 수 $n_c$가 불균등한 `paired_demo`(40명 페르소나, 10개 셀 인원수 $n_c \in \{2, 3, 4, 6, 7\}$)에서는 셀 $c$의 총 가중치가 $\sum_{i \in c} w_i = n_c \tilde{w}_c$로 왜곡되어 정규화 후 셀 비중이 $\frac{n_c \tilde{w}_c}{\sum_{c'} n_{c'} \tilde{w}_{c'}}$로 변질되었다.
- **수정**: [`kgss_metrics.py`](../kgss_metrics.py)의 [`build_cell_poststratified_row_weights()`](../kgss_metrics.py#L254-L309)를 통해 각 프롬프트 행 $i \in c$에 **셀 가중치 나누기 셀 내 인원수**를 부여하였다:
  $$w_i = \frac{\tilde{w}_{c(i)}}{n_{c(i)}}, \qquad \tilde{w}_c = \frac{w_c}{\sum_{c' \in C_{\text{obs}}} w_{c'}}$$
  이 정의에 의해 모든 관측 셀 $c \in C_{\text{obs}}$에서 다음 두 구조적 불변식(Invariant)이 항등적으로 성립하며, `score()` 실행 시 매 문항마다 오차 한계 $10^{-10}$ 이내로 런타임 검증된다:
  1. **셀 가중치 보존 불변식**: $\sum_{i \in c} w_i = n_c \cdot \frac{\tilde{w}_c}{n_c} = \tilde{w}_c$
  2. **셀 평균 선집계 동치 불변식**: $\sum_{i=1}^N w_i P_i = \sum_{c \in C_{\text{obs}}} \tilde{w}_c \left(\frac{1}{n_c}\sum_{i \in c} P_i\right) = \sum_{c \in C_{\text{obs}}} \tilde{w}_c \bar{P}_c$

### 2.1 255개 문항 전수 분류표 ([`audit_outputs/item_classification_255.csv`](./item_classification_255.csv)) 및 `13 vs 14` 불일치 해소

### 2.2 프롬프트 결함 9개 문항의 정확한 목록과 현재 처리 상태
`c0_check/probes.csv` 실제 프롬프트 원문을 전수 대조하여 확정한 9개 결함 문항은 다음과 같다.
1. **`문항: nan` (설문원문 결측) 6개**:
   - 원인: [`kgss_c0_validity.py`](../kgss_c0_validity.py) 구 line 146의 `txt = str(worded.get(v, "") or "")`에서 `worded.get(v)`가 `float('nan')`을 반환할 때 Python에서 `bool(float('nan')) == True`이므로 빈 문자열로 대체되지 않고 `"nan"` 문자열이 생성됨.
   - 해당 문항(6개):
     - **`SAMPLEAB`** ($K=2$, 설문지 유형 A/B): **조사 행정변수이므로 평가 문항에서 영구 제외**.
     - **`HATOPSEX`** ($K=5$, 이성에 대한 혐오 심각성 인식), **`HHSEX`** ($K=2$, 가구주 성별), **`HHMARI`** ($K=6$, 가구주 혼인상태), **`HHAWAY`** ($K=2$, 가구주와 동거여부), **`HHEMPLY`** ($K=2$, 가구주 취업여부): 5개 실질 문항.
2. **결측/무응답/비해당 보기 유출 (`leaked_dk_or_inap`) 3개**:
   - 원인: `inventory/variables.csv`의 `legacy_dk`/`legacy_inap`가 빈 리스트(`[]`)로 잘못 등록되어 `real_options()`가 결측 보기를 걸러내지 못함.
   - 해당 문항(3개): **`MEDIAPOL`** (`8. DK/Refusal` 유출), **`HLPRT1`** (`8. DK/Refusal`, `9. Not Applicable` 유출), **`HUMNAT`** (`8. DK/Refusal` 유출).
3. **현재 상태 구분 (수정 적용 vs 미검증 한계)**:
   - **코드 수정 적용**: [`kgss_c0_validity.py`](../kgss_c0_validity.py)에 `--clean-prompts` 옵션을 추가하여 `SAMPLEAB` 자동 제외, `DK/Refusal/Not Applicable` 보기 필터링, `설문원문`이 `NaN`일 때 `표제목`/`label`로 안전하게 대체하도록 수정하였다.
   - **현재 캐시 영향**: 이 9개 문항은 현재 로컬 추론 캐시 4종(`c0_cached` 197개, `adult_cached` 145개, `paired_demo` 125개, `full` 6개) 중 **어느 곳에도 포함되어 있지 않다(교집합 0개)**. 따라서 현재 보고서의 125문항·6문항 재계산 결과는 이 9개 프롬프트 오류에 의해 오염되지 않았다.
   - **미해결 한계**: 원본 255개 전체 문항 결과(`c0_check*/c0_validity_result.md`)에는 이 9개 문항이 포함되어 있으므로, 8개 실질 문항(`HATOPSEX`, `HHSEX`, `HHMARI`, `HHAWAY`, `HHEMPLY`, `MEDIAPOL`, `HLPRT1`, `HUMNAT`)의 수정 후 모델 성능은 GPU 환경에서 LLM 재추론을 수행해야 확정할 수 있으며, 재추론 전까지는 평가 모수에서 **제외(246개 정제 문항 기준)**하는 것이 타당하다.

## 4. `subgroup r` 중심화 재검증, 보수적 해석 및 다중 불확실성 감도 분석

### 4.1 지표의 수학적 의미와 "$R^2$ 설명분산" 오해석 배제
- 수정된 `centered subgroup r`은 각 성별×연령 셀 $c$ 내부에서 문항 $v=1,\dots,V$에 걸쳐 인간 셀 편차 $\Delta_{\text{human}}(v,c) = \mu_{\text{human}}(v,c) - \bar{\mu}_{\text{human}}(v)$와 모델 셀 편차 $\Delta_{\text{model}}(v,c) = \mu_{\text{model}}(v,c) - \bar{\mu}_{\text{model}}(v)$의 문항 간 피어슨 상관계수 $r_c$를 구한 뒤 10개 셀에 대해 평균한 값($\bar{r} = \frac{1}{10}\sum_{c=1}^{10} r_c$)이다.
- **해석상 주의점**:
  1. $\bar{r}$은 10개 셀 상관계수들의 산술평균이므로, **평균 상관계수 $\bar{r}$을 단순 제곱하여($\bar{r}^2$) "하위집단 분산의 3.4% 또는 1% 미만을 설명한다"고 해석하는 것은 수학적으로 부적절하므로 철회**한다(단일 회귀모형의 결정계수 $R^2$가 아니며, 문항 간 척도 폭의 영향을 받는다).
  2. 개별 문항 내부에서 10개 셀의 순위/선형 배열을 맞히는 **문항 내 상관(`within-item r`)**과 구분하여 보고해야 한다.

### 4.2 문항 부분집합별 `subgroup r` 및 4단계 부트스트랩 감도 분석 (`paired_demo`)

## 6. [세컨 골: 범용 Antigravity Harness 개선]

- **발견한 범용 실패 패턴**: 단위 테스트가 개별 헬퍼 함수(`aggregate_demo_cells`)만 검증하거나 셀당 표본 수가 1개인 단순 케이스($n_c = 1$)만 검증할 경우, 실제 상위 호출자(`kgss_c0_validity.score()`)가 헬퍼 출력값을 받아 행 단위 가중치 배열로 재배선(wiring)하는 과정에서 다중 표본($n_c > 1$, 불균등 셀 인원수) 가중치를 중복 부여하는 **호출부 배선 오류(Caller-Helper Wiring Bug)**가 기존 단위 테스트를 통과하는 실패 패턴을 확인하였다.
- **적용한 재발 방지 장치와 검증 근거**:
  1. **호출 경계 런타임 구조적 불변식(Runtime Structural Invariant) 강제**: [`build_cell_poststratified_row_weights()`](../kgss_metrics.py#L254-L309) 및 [`kgss_c0_validity.score()`](../kgss_c0_validity.py#L316-L321) 내부에 (i) 모든 관측 셀 $c$에서 행 가중치 합이 정규화 셀 가중치와 일치하는지($\left|\sum_{i \in c} w_i - \tilde{w}_c\right| \le 10^{-10}$), (ii) 행 가중 집계 분포가 셀 평균 선집계 분포와 일치하는지($\max_k \left|\sum_i w_i P_i(k) - \sum_c \tilde{w}_c \bar{P}_c(k)\right| \le 10^{-10}$)를 매 문항 실행 시 자동 검증하는 `AssertionError` 가드를 내장하였다.
  2. **불균등 셀 크기($n_A=1, n_B=9$) End-to-End Caller 통합 테스트 추가**: [`tests/test_kosmos_audit.py`](../tests/test_kosmos_audit.py#L339-L445)의 `test_12_unequal_cell_size_end_to_end_score_invariant`에서 실제 `score()` 함수를 End-to-End로 호출하고 생성된 CSV를 독립적인 셀 평균 선집계 수식과 전 지표($W_1$, TVD, 조건부/모집단 엔트로피, 상호정보량)에서 $10^{-12}$ 정밀도로 대조하여 12개 테스트 전수 통과를 확인하였다.
- **아직 남은 한계**: 현재 불변식 가드와 통합 테스트는 추론 완료 후 채점(`score`) 및 프롬프트 생성(`build --clean-prompts`) 단계의 수리적·구조적 무결성을 보장하지만, GPU 추론 단계(`kgss_token_check.py`)에서 발생할 수 있는 토크나이저-선택지 매핑 변칙이나 미수집 캐시 구간(246개 정제 문항 전수)의 실측 성능은 오프라인 단위 테스트만으로 대체할 수 없으므로 실제 모델 재추론 파이프라인 실행 시 동일한 End-to-End 불변식 검사를 연동해야 한다.
